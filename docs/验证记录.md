# v3.0 验证记录

验证日期：2026-10-20。测试仅使用人工测试数据，不含真实新增项目材料。

## 已完成

- `npm test`：3个测试文件、11项自动化测试通过。
- `npm run build`：TypeScript 检查及 Vite 生产构建通过。Excel 导出依赖按需加载。
- 自动化测试涵盖：完整快照保存及引用隔离、各账号本机键隔离、JSONB字段重排去重、同编号内容冲突保护、损坏备份、存储满错误、日期及文本筛选、金额换算。
- Excel 写出后重新读取：核对全部发行字段、前导零代码、原文/成稿、数值金额/利率、筛选和冻结窗格；以文本写入以“=”开头的发行人名称，未转换成公式；超长原文拒绝静默截断。
- 云接口自动化测试：1101笔记录分页读取、201笔记录分批上传、仅忽略相同用户内的重复记录、拒绝私钥配置及网络错误上抛。
- 隔离 Chromium 浏览器生产包测试：必填不齐不能归档，完整归档后刷新可读，历史详情可打开，单笔XLSX实际下载，修改历史另存且原快照不变，关键词筛选。
- 1440像素桌面及390像素手机视图检查，手机台账和详情无横向溢出。
- 两个隔离浏览器上下文配合模拟 Supabase Auth/REST：本机导入账号、设备一上传、设备二读取及新增、设备一刷新读取、退出回到本机台账并清空表单、账号B与账号A台账隔离。

## 开通后必须进行的实测

尚无用户实际 Supabase 项目，故没有对真实云端账号、实际建表执行、RLS授权、邮件送达和两台真实设备的公网访问作完成确认。模拟接口测试不能替代这些检查。

完成《云端开通指南》中的两端同步及不同账号隔离步骤后，才可确认实际共用存储已经启用。
