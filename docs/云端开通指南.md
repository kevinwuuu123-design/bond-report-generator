# 手机和电脑共用记录：Supabase 开通指南

本次代码已接入云端能力。实际共用存储需要你创建属于自己的 Supabase 项目并完成下列一次性设置。

## 1. 创建项目

打开 [Supabase 控制台](https://supabase.com/dashboard)，注册并创建项目。选择你手机和电脑均能稳定访问的区域。数据库密码自行妥善保存，不需要填写到生成器中，也不需要发送给他人。

项目套餐、额度和邮件限制以控制台当前显示为准。开通后先用测试数据验证手机与电脑的网络可达性。

## 2. 建表并启用账号隔离

打开项目 **SQL Editor → New query**，复制仓库中的 [`supabase/schema.sql`](../supabase/schema.sql) 全部内容并运行。

脚本创建 `bond_records`，启用行级安全（RLS），只允许已登录用户读取及插入自己的记录。匿名访问无数据权限，普通账号也没有改写、删除已归档记录的权限。

运行后在 Table Editor / Authentication 中分别检查表与登录用户。不要关闭 RLS 或另外添加“所有用户可读写”的策略。

## 3. 设置邮箱登录

在 **Authentication → URL Configuration** 中将 Site URL 设为实际网站地址。当前仓库默认 Pages 地址为：

`https://kevinwuuu123-design.github.io/bond-report-generator/`

若你使用自定义域名，请使用实际域名，并将相应网址加入 Redirect URLs。开发测试时可另加入本地开发地址。

在 **Authentication → Providers / Sign In** 中启用 Email，设置最少8位密码，保留邮箱确认。正式使用的邮件发送请按 [Supabase 邮件设置文档](https://supabase.com/docs/guides/auth/auth-smtp) 配置 SMTP；默认测试邮件可能有收件人及频次限制。

可在 Authentication → Users 中由项目管理员创建并确认自己的账号，或通过网站“注册账号”完成邮箱验证。不要在公共网站上填写数据库管理员密码。

## 4. 连接项目

在项目 **Connect / Settings → API Keys** 找到 Project URL 和 **Publishable key**（旧项目也可使用 anon 公钥）。

推荐在 GitHub 仓库 Settings → Secrets and variables → Actions → **Variables** 新建：

| 变量 | 内容 |
| --- | --- |
| `VITE_SUPABASE_URL` | `https://你的项目编号.supabase.co` |
| `VITE_SUPABASE_PUBLISHABLE_KEY` | `sb_publishable_...` 或旧版 anon 公钥 |

保存后打开 GitHub Actions，选择 **Deploy to GitHub Pages → Run workflow**。部署完成，手机和电脑刷新网站即可使用同一个项目。

也可在生成器的“手机 / 电脑共用存储 → 项目连接配置”手动填写，需在两台设备各填写一次。手动配置会覆盖该设备上的部署默认值。

**不得填写 `service_role`、`sb_secret_` 或数据库密码。** 公钥可以出现在浏览器中，访问控制由数据库策略和已登录账号完成。

## 5. 验证两端共享

1. 电脑登录邮箱账号，补齐一条测试报备，完成归档，点击“立即同步”，确认待同步数为0且无错误。
2. 手机打开同一网址，使用同一邮箱账号登录，点击“立即同步”，确认能打开电脑的测试记录。
3. 手机完成另一条测试记录，电脑刷新或点击同步，确认也能看到。
4. 在两端分别导出 Excel，检查债券代码、金额、原文和记录编号一致。
5. 已有未登录记录时，点击“将本机记录导入账号”；若来自其他浏览器，先备份 JSON，再登录目标账号导入。
6. 另建测试账号B，确认看不到账号A记录。未登录也不应读取账号A记录。

## 常见问题

- **同步失败 / 表不存在**：检查建表脚本是否成功运行、两台设备项目地址是否相同，确认没有拼错公钥。
- **Permission denied / RLS 错误**：确认已登录，重新运行仓库原版建表脚本并检查策略；不要用关闭RLS的方法处理。
- **注册邮件未收到**：检查垃圾邮件及 Supabase 邮件发送日志、SMTP配置和频率限制，也可以由管理员在控制台创建并确认账号。
- **暂时断网**：已在本机归档的记录保留；恢复联网后手动同步或等待自动同步。页面不能在完全离线且未打开过的设备上首次加载。
- **退出后记录“消失”**：退出后显示未登录台账。重新登录原账号可查看该账号记录；本机账号缓存与未登录记录相互隔离。
- **记录格式异常 / 存储已满**：先备份 JSON，保留浏览器现有数据。不要清理浏览器或覆盖异常备份。若无法正常读取，应从开发者工具导出对应 `bondArchivesV1:` 原始存储值。

开发参考：[Supabase 密码登录](https://supabase.com/docs/reference/javascript/auth-signinwithpassword)、[数据写入接口](https://supabase.com/docs/reference/javascript/upsert)、[行级安全](https://supabase.com/docs/guides/database/postgres/row-level-security)。
