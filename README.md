# 债券簿记内部报备生成器 v2.1

一个纯前端、浏览器本地运行的债券簿记后内部报备工具。粘贴簿记结果后，系统自动识别发行要素、推定簿记/起息/归档日期、提示缺失字段，并生成固定内部报备段落。

## v2.1 重点
- 数据工作台式 UI：KPI、识别提示、分区表单、待补清单、实时成稿。
- 必填缺失红色高亮；条件项黄色提示；右侧可一键跳转到待补字段。
- 担保二选一并条件展开担保人名称。
- 牵头机构和角色分离，避免“我司”直接落句造成表述生硬。
- 我司承销规模/承销费提供 5 种常用口径。
- 存续期负责人和执行人员在复制报备时自动记忆到浏览器 localStorage。
- A 类敞口使用/未使用切换，未使用时不再要求填写额度。
- 未来年度节假日未公布时继续给出暂估日期并明显提示。

## GitHub Pages 更新方式
1. 解压本 ZIP。
2. 将 ZIP 内文件复制到你现有 `bond-report-generator` GitHub 本地仓库根目录，覆盖同名文件；不要删除 `.git` 文件夹。
3. 在 GitHub Desktop 中确认变更，Commit message 可写 `Upgrade to v2.1 dashboard`。
4. `Commit to main` 后点击 `Push origin`。
5. GitHub Actions 会自动重新部署 Pages。

## 隐私
项目为纯前端，输入的项目数据仅在本地浏览器运行；除非你主动把数据写入代码并提交，否则不会被上传到仓库。
